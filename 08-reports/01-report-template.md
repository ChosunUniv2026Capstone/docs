# 캡스톤 공통 보고서 양식

이 양식은 주간보고서, 중간보고서, 최종보고서에 공통으로 사용한다.
주간보고서와 중간보고서는 **목표 대비 달성치**를 중심으로 작성하고, 최종보고서는 같은 항목을 최종 완료 상태로 정리한다.

- 보고서 종류: 주간 / 중간 / 최종

- 완료해야 하는 핵심 산출물

# 3. 필요성 및 배경

- 기존 사이버캠퍼스의 한계

- 학교 현장 적용 시 기대효과
